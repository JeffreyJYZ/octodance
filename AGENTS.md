# octodance

Published: <https://github.com/JeffreyJYZ/octodance> (public; `main` tracks `origin/main`).

## Stack

- Next `16.3.8` (App Router, Turbopack) + React `19.3.0`
- TypeScript `7.0.2` (native port), `strict`, path alias `@/*` → `./src/*`
- Tailwind CSS `4.3.3` via `@tailwindcss/postcss` (`src/app/globals.css` = `@import "tailwindcss";`)
- Biome `2.5.15` — formatter + linter (tabs, width 4)

## Commands

- Package manager: **bun**.
- `bun dev` · `bun run build` · `bun check` (= `biome check --write`)

## Gotchas

- **Next rewrites `tsconfig.json` on first build** (`jsx`, `allowJs`, `lib`, 2-space). Run `bun run check` (or `biome format --write`) to restore tabs; next build leaves it alone.
- Biome 2.5 deprecated `linter.rules.recommended` → use `"rules": { "preset": "recommended" }`.
- Biome ignores `.gitignore`; `.next`/`node_modules` excluded explicitly in `biome.json` (`files.includes`).
- **Fonts**: defs `src/ui/fonts.ts` (`next/font/local`), assets `public/fonts/`, consumed in `src/app/layout.tsx` via `@/ui/fonts`.
  - `Satoshi-Variable.woff2` + `Satoshi-VariableItalic.woff2` → `--font-satoshi` (weight `300 900`) → Tailwind `--font-sans` (default body font).
  - `CODE-Light.otf` (300) + `CODE-Bold.otf` (700) → `--font-code` → Tailwind `--font-display` (`font-display`). Code Pro is a display face, **not** mono.
  - Source `~/dev/fonts` (`satoshi/`, `code/`); copy in, commit.
  - **Build emits them twice, accepted**: `next/font/local` copies each to `.next/static/media/<hash>` (referenced by built CSS) while `public/fonts/` serves the originals (unreferenced). Not a bug — keep `next/font/local` (preload + fallback metrics), not hand-rolled `@font-face`.
- **Client-component barrels break Turbopack builds.** Server Component importing Client Component through a barrel `index.ts` lacking `"use client"` fails `Export X doesn't exist in target module` ("module has no exports at all"). Import the file directly, or add `"use client"` to the barrel. Components are flat files — keep imports direct.
- Biome needs **`css.parser.tailwindDirectives: true`** to parse `@theme`/`@import "tailwindcss"` in `globals.css`; else `biome check` errors on Tailwind syntax.

- **Drawing persists in `localStorage`** (`src/lib/canvas/persist.ts`; keys `octodance:drawing:v1`, `octodance:palette:v1`). Strokes live in refs, so reload wipes work (HMR reload too). Saved on each commit/undo/clear and `beforeunload`/`pagehide`, restored on mount; clearing **removes the key**, not stores `[]`. On mount in-memory strokes win when non-empty (an HMR reload can hold newer than storage) and get written back. Encoding compact (flattened `[x,y,…]`, rounded coords, kind tags `"i"`/`"e"`); decode validates every field. Gotcha: kind-tag mismatch between encode and decode rejects *every* stroke silently — storage looks fine but nothing restores.

## Components

- Flat files under `src/ui/components/`, one component per file, **no per-component folder**. Import as `@/ui/components/<name>`.
- **Music**: 3 bundled CC0 demo tracks (`DEMO_TRACKS` in `canvas.tsx`; `public/music/`; provenance `CREDITS.md`), load+play one click via `useAudio().loadUrl()`, plus upload fallback. Figure is **audio-reactive** (`rig.ts`: bass→sway, mid→bob, high→tilt, beat→snap) — barely moves with no track.
- `canvas.tsx`: drawing UI + **Edit mode**. Hand-rolled `<canvas>` (no drawing lib) + `react-colorful` `HexColorPicker`; palette swatches (custom removable, `Add` disabled when present); thickness/preview; Draw/Eraser; Undo/Clear via stroke-model history (cap 30). DPR-aware, **no fixed height**, sized from `parent.clientWidth/clientHeight` (border excluded, else overflows/clips); `absolute inset-0` in the left grid cell so the control column drives row height and columns stay equal.
- **Two modes over one stroke model** (`src/lib/canvas/`): *Edit* renders the in-progress stroke through the **same** `renderScene` (appended to the render list each move) — live view *is* committed view, **releasing a stroke never changes it**; a separate live path popped/thinned strokes on release — do not reintroduce it. *Play* runs a `requestAnimationFrame` loop redrawing the whole scene each frame with audio-driven motion. Nothing animates while drawing; drawing is ignored while playing.
  - `strokes.ts` — pure geometry: `Point`/`InkStroke`/`EraseStroke`/`Stroke` (points normalized 0..1, `width` a fraction of `min(w,h)`). No per-stroke motion data.
  - `rig.ts` — articulation rig. Contacts by proximity (≤ `JOIN_EPS_PX`, endpoint to another stroke's path); strokes become **bones rotating about their own contact endpoint**. Joints stay closed: (a) pivot the child's *own* point, never the midpoint (midpoint pivot opens gap up to half contact distance); (b) a pair touching at **≥ 2 points**, or any contact that would **close a loop**, merges into one rigid `RigGroup` (they cannot articulate relative to each other — as separate bones the second hinge tears open). Unconnected strokes attach by **containment**: a bbox enclosing another with ≥ `CONTAIN_MARGIN_PX` spare every side binds to the tightest container, `swing 0`. Containment only — do **not** use proximity/single-linkage, which drags unenclosed outer strokes onto the main shape. Margin must **shrink** the container, not pad it (a padded test lets a thin curve overlapping a dot claim it). Do not reintroduce "anchored" ("attach to nearest stroke already reaching a joint"): a cluster whose only edge is between its own members counts as anchored and never bridges, leaving a dot at `parent=null` (roots=2) while the shape swings. Enclosed parts follow their container; the rest stay their own root, still receiving the whole-figure global transform. Contacts test **endpoints only** (`ends()` = first/last point), so two closed loops never join however close. **Verify against real strokes, not pixel metrics** — a detached dot can read as moving; the tree is the only proof. Seed the user's drawing from `localStorage`: scan Chrome LevelDB (`~/Library/Application Support/Google/Chrome/Default/Local Storage/leveldb/`), key `octodance:drawing:v1`, take the most-strokes entry, seed via `agent-browser eval --stdin`, dump `window.__rig`. Debug: expose the rig on `window`, print `groupOf`/`parent`/`swing` — the tree proves attachment, not pixel diffing. `rigMatrices` = one matrix per group, `time`-based (~0.33 s ease-in ramp so playback start does not snap).
  - `render.ts` — `renderScene(ctx, strokes, features, time, w, h, intensity)`; while animating applies each stroke's **group** matrix (`rig.groupOf[strokeIndex]`) then draws it. Ink strokes draw a per-frame **wiggled** path (`buildWiggledPath`: sub-pixel, time-varying offset tapered to zero at both ends so joints stay welded); erase strokes keep the cached path. Still/editing (`isStill(features)` or intensity 0) uses identity transforms + plain cached paths, so **live == committed**. Cache key must include canvas size **and point count** (an in-progress stroke grows while drawing), else the live stroke renders stale/truncated.
  - **Motion design constraints (each a real bug, do not regress):** per-stroke *transforms* (translate/scale) pull joints apart — bones must **rotate about the joint**. A single whole-scene rigid transform keeps joints but reads as the whole thing moving on its own, too subtle; a per-point displacement field welds joints but squeezes/stretches the drawing; pivoting on the contact midpoint opens a gap. Feature values after the gamma curve sit near ~0.2 — scale them before multiplying by amplitudes or nothing visibly moves. Per-limb **random** `freq`/`phase`/`dir` makes six limbs jitter on unrelated clocks — derive from position instead. Applying beat *instantly* at high amplitude teleports the pose, reads as jitter — ease each group's angle toward target (`RigGroup.angle`), keep `swing` moderate.
  - **Verifying motion** (no test suite): measure frame-to-frame **pixel change**, never ink centroid (limbs rotate randomly, so centroid motion cancels out and hides the effect). Bursty p90/median ≈ 2.5–5 = beat-driven, ≈1 = static or constant wobble; ink **connected-component count must not exceed its static value** — joint-tearing test. Drive the page with `agent-browser`, or diff frames from a screen recording (`ffmpeg -vf "crop=W:H:X:Y,fps=30,scale=230:268,format=gray" -f rawvideo -pix_fmt gray`).
  - `audio.ts` — `useAudio()`: upload (`load(File)`) or bundled demo (`loadUrl(url, name)`) → `decodeAudioData` → source → `AnalyserNode` (smoothing 0.5); `sample()` returns bass/mid/high/level/beat at call time (never React state), consumed by the rAF loop; spectrum bins get a gamma curve so dynamics read. `beat` is an **onset**: rise in raw time-domain energy (`getByteTimeDomainData`, unaffected by `smoothingTimeConstant`) above an adaptive baseline, 180 ms refractory. **Do not detect with a level ratio on `bass`** — on a loud sustained track `bass` sits within a hair of its own average, so the ratio never fires. Keep ~40-frame warm-up or every frame at playback start counts as a beat.
  - Loop/stroke state in refs (no per-frame `setState`); resize re-renders from model, history survives.
